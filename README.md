# Breast Cancer Survival Prediction

An end-to-end machine learning pipeline for predicting breast cancer patient survival using the SEER Research Database and Apache Spark MLlib.

---

## Features

- Large-scale data processing with Apache Spark
- Data preprocessing pipeline
- Feature engineering
- Multiple machine learning algorithms
- Model evaluation and comparison
- Reproducible project structure

---

## Dataset

Source:
SEER Research Data (National Cancer Institute)

Incidence - SEER Research Data, 17 Registries, Nov 2025 Sub (2000–2023)

Cancer type:
Breast Cancer 

Diagnosis years:
2004–2015

Target variable:
Vital Status (Alive / Dead)

---

- Decision Tree
